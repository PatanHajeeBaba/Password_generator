# Password_generator
-- A sleek, high-performance web tool for crafting unbreakable passwords. Built with a focus on clean UI/UX and customizable security.

## PassForge – Craft Unbreakable Passwords

-- PassForge is a modern, responsive web application designed for users who take their digital security seriously. It eliminates the "human element" of weak password creation by generating cryptographically strong strings based on user-defined parameters.

### ✨ Key Features

-- Fully Customizable: Toggle between lowercase, uppercase, numbers, and symbols.

-- Dynamic Length: Adjust password length (up to 32+ characters) with a smooth slider interface.

-- One-Click Copy: Quickly copy your new password to the clipboard with visual feedback.

-- Cyberpunk Aesthetic: Features a high-contrast, dark-mode "Forge" UI for an immersive experience.

-- Client-Side Security: All generation happens in your browser—no data is sent to a server.

### 🛠️ Tech Stack

-- HTML5 & CSS3: Utilizing Flexbox/Grid and custom transitions for that glow effect.

-- JavaScript (ES6): Logic-driven generation using the Math.random or Crypto.getRandomValues() API.
